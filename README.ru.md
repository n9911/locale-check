# Locale Check

<img src="src/assets/icon.svg" width="88" alt="Locale Check">

Сверка ключей JSON и плейсхолдеров перевода. Локальный инструмент 0.1.0, JavaScript / Node.js.

## Запуск

Node.js 22+. Windows: Start.cmd. macOS/Linux: sh start.sh. Откройте http://127.0.0.1:8835/. Порт можно задать переменной PORT. Сервер слушает только 127.0.0.1 и отдаёт фиксированный список файлов. Не открывайте index.html напрямую: ES modules требуют HTTP.

Нажмите «Пример», затем «Обработать», изучите результат и сохраните нужные файлы по ссылкам экспорта. Для файловых задач выберите разрешённые файлы вручную.

## Данные

- **Исходный JSON** (textarea).
- **Перевод JSON** (textarea).

Ввод, вычисления и файлы остаются в браузере. Сохранение полей на этом устройстве — только по кнопке; выбранные файлы не сохраняются. «Удалить сохранённое» удаляет только сохранённые поля этого приложения. Локальное хранение не зашифровано: не используйте общий профиль браузера для чувствительных данных. Результат экспорта проверяйте перед переносом в рабочую систему.

## Границы

Не оценивает смысловую точность перевода. Нет сетевой публикации, синхронизации между людьми или автоматических платных запросов. Mac/Linux не проверены на настоящих устройствах.

## Интерфейс и локальные проекты — 04.11.2026

Интерфейс, поля, собственные ошибки и служебные подписи доступны на русском,
английском и испанском. Пользовательские тексты не переводятся. При первом открытии
язык выбирается из настроек браузера; тема следует системе. Изменённые язык и тема
сохраняются в localStorage. Сайдбар имеет ширину 250 px; на узком экране открывается
кнопкой меню, таблицы прокручиваются внутри результата.

«Сохранить проект» записывает один снимок в IndexedDB; «Открыть сохранённый» явно
восстанавливает его. Галочка позволяет включить выбранные файлы. Без неё файлы
выбираются повторно. «Удалить сохранённый» удаляет снимок и старое сохранение ввода,
сохраняя текущую форму, тему и язык. Автосохранения документов нет.

Показана оценка места браузера; постоянное хранение запрашивается отдельной кнопкой
и может быть отклонено. Данные привязаны к адресу, порту и профилю браузера. Очистка
данных сайта может их удалить; нужен отдельный экспорт и резервная копия.

Приложен manifest и service worker: после первого успешного открытия и заполнения
кэша приложение работает офлайн. В поддерживаемом браузере доступна установка PWA.
Настоящая установка в ОС здесь не подтверждена. Обновление не перезагружает страницу
самостоятельно: сначала сохраните проект, затем примите обновление. Изменённый сервер
нужно штатно перезапустить, открытой вкладке — обновить страницу.

Иконки SVG, PNG 192/512 и Windows ICO различаются по назначению проекта. Ни SQLite,
ни облако для этого сценария не нужны. Код автономен: i18n.mjs/messages.mjs,
preferences.mjs, drafts.mjs, pwa.mjs и sw.js находятся в этой папке.
